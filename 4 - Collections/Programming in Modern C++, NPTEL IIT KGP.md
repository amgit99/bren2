### Objectives and Course Outline
- Features of C++ over C.
- OOPS functionality in C++
- Code reuse with STL.
- Features of C++11 over C++98/03
- Concurrent programming of C++.
- Better quality(lambdas) and efficiency by C++.

##### Week 1: 
- Introduction, I/O, Loops, Arrays Vectors, Sorting in C/C++, Stacks, Queues etc.
##### Week 2: Procedural Extensions of C
- `const`- ness and `inline` functions
- References, alias, Call by value, Call by reference, Return by value, Return by Reference
