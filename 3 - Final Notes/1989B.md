<span style="color:#e1db3d">Question</span>: Find the smallest length string that has *$a$* and substring and $b$ as subsequence.

<span style="color:#00b050">Answer</span>: We know the minimum size of the solution is the size of the substring. And an upper-bound to this value that we are looking for is the sum of the lengths of $a$ and $b$.
The solution lies somewhere in the middle, we need to find that, we can do it using binary search over the range of $|a|$ and $|a| + |b|$. For every number for which we decide to search if there exists a valid solution, we choose the smallest one.
<span style="color:#e1db3d">The overlap, if one exists will be a substring of</span> $b$ <span style="color:#e1db3d">and will appear as a subsequence in</span> $a$.
To check if the solution is valid or not, we do the following:
- Find the overlap, overlap will be equal to the sum of string sizes minus the number we are checking for in the iteration of binary search.
- Then we check for every substring of the subsequence of that size, if it is a part of the substring, If it is, then we have found a solution.
