<span style="color:#e1db3d">Problem Statement</span>: Given an array $a$ of integers of size $n$, we can perform a certain type of operation. Pick any two adjacent elements, $a_i$ and $a_{i+1}$ and add any value $k$ where $k \in Z$ to them, $Z$ is the set of integers.
Our task is to tell if it is possible to make the array strictly non decreasing.

<span style="color:#00b050">Solution</span>: The solution is based on the changes in the difference array, let's call it $b$. This array is of length $n-1$ and is obtained by taking the differences of  $a_{i+1} - a_i,\ \forall i \in \{1, n-1\}$
Lets call these differences $b_1 ... b_{n-1}$. 

It is apparent that he values of the array $b$ should always be non-negative for the array $a$ to be non-decreasing. So if we are able to make array $b$ non-negative, then we have a solution.   $(1)$

When we make an operation the the main array $a$ the observed change in the array $b$ is is of a certain type, When we move the pair of elements, $a_i, \ a_{i+1}$ by some value $k$, the corresponding difference $b_i$ stays same obviously, but he amount of change in $b_{i-1}$ and $b_{i+1}$ is $|k|$ but in opposite directions. If the number added, $k$ is positive then $b_{i-1}$ will increase by $|k|$ and $b_{i+1}$ will decrease by $|k|$.   $(2)$ 

Now, we can increase $b_2$ and $b_{n-2}$ vastly by simply subtracting and adding a huge $k$ to the pairs $\{a_1, a_2\}$ and $\{a_{n-1}, a_n\}$ respectively (taking the first pair down and the last pair up). Note that $b_1$ and $b_{n-1}$ stay the same and the ones on the left and right get affected. 

We now only focus on how the difference array behaves. We know that by performing the operations, we can change the values of the difference array $b_i$ by some amount and the same will be reflected in the opposite direction for $b_{i±2}$ depending on which pair of elements we choose. We notice here that the parity of elements among which the values are distributed is same. The value that reduces from $b_i$ can never end up in the difference values of opposite parity $b_{i±1}, b_{i±3}, b_{i±5}...$ So, if the sum of such unreachable parity is less than zero then $(1)$ does not stand and we have no solution.

In case of odd $n$, the two ends that we increase $b_2$ and $b_{n-2}$ end up having different parities, 
$2$ is even and $(n-2)$ is odd since $n$ is odd. So every  element of $b$ is covered. We can make all of them positive by distributing the values.
In case of even $n$,  $b_2$ and $b_{n-2}$ both have the same parity, i.e even. So the $b_s$ in the odd parity can never have any additional values, and their sum will stay the same. This is because we can only add value to these specific end values  $b_2$ and $b_{n-2}$  because there is no $b_0$ and $b_n$ to be affected. So the solution now only exists if the sum of the odd parity $b$ values is greater than zero.
