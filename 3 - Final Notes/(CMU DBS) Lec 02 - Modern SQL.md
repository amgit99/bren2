Goes back to the 1970s, IBM took Codd's paper and decided to make a language for this sort of a system, and called it <span style="color:#e1db3d">Square</span>. It did not go anywhere, later they refined it and called this version SEQUEL. It got sued by a company with that name and got it renamed it to <span style="color:#e1db3d">SQL</span>. In 1986 it got an ANSI Standard. The following is the requirements for an implementation to be compliant ![[sql_standard_changes.png]]

$SQL \; will \; not \; die \; before \; our \; lifetime$  ~ Andy Pavlo

Although the relational model is based on <span style="color:#e1db3d">sets</span>, SQL is based on <span style="color:#e1db3d">bags</span>.
SQL is standardized, but when it comes to datetime and other types, the different systems start to drift apart.
